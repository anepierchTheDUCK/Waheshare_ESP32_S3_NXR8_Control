# Waheshare_ESP32_S3_NXR8_Control
This is a simple software that allows you to check if your Waheshare ESP32 S3 NXR8 development board is working properly.

You need an LCD I2C screen, a breadboard, three resistors, four female cables, four male-female cables and a Type-C cable.
First, you need to install the Adafruit_NeoPixel and LiquidCrystal_I2C libraries.
